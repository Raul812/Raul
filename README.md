# ZHIBIN · Personal Website

一个纯 HTML / CSS / JavaScript 的个人网站，适合直接部署到 GitHub Pages。

## 文件结构

- `index.html` — 首页
- `about.html` — 关于
- `projects.html` — 项目
- `notes.html` — 思考记录
- `lab.html` — 实验室
- `now.html` — 当前状态
- `css/style.css` — 全部样式
- `js/main.js` — 菜单、深浅色切换
- `assets/` — 图片等资源

## 部署到 GitHub Pages

1. 在 GitHub 创建一个仓库。
2. 将本项目所有文件上传到仓库根目录。
3. 打开 `Settings` → `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. Branch 选择 `main` / `root`。
6. 保存，等待 GitHub Pages 发布。

如果仓库名称是：

`你的用户名.github.io`

网站地址通常就是：

`https://你的用户名.github.io/`

## 修改个人信息

建议优先修改：

- 所有页面里的 `Huang Zhibin`
- `mailto:your@email.com`
- About 页面内容
- Projects 页面内容
- Notes 页面内容
- Now 页面日期和状态

目前没有使用外部框架、构建工具或第三方字体，上传后即可运行。
